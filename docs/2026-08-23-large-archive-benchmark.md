## 结论口径

本报告记录的是当前机器实测值，不外推其他硬件。初始文件树只返回固定根节点，目录展开只读取直接子项；导出按目录稳定排序并直接写 Zip，不预先收集全部路径；反编译通过 CFR 主 API 分批执行。20 万条目是当前默认条目上限，超过上限会被资源门禁明确拒绝。
